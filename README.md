# 먼작주

Windows와 macOS에서 돌아다니며 관심종목 가격을 알려주는 독립 데스크톱 펫입니다. 시세는 각 사용자의 토스증권 Open API로 직접 조회합니다. 소리는 재생하지 않습니다.

## 0.5.0 먼작주

앱 이름을 **먼작주**로 변경하고 생성 로고, TmoneyRoundWind 글꼴, 색상을 맞춘 제목 표시줄과 버전 표시를 적용했습니다. 장식용 작은 문구와 알림기록 탭을 제거하고 하단에 투자 판단 책임 안내를 표시합니다. 앱 아이콘은 유지합니다.

치이카와·하치와레·우사기의 16포즈 이미지를 모두 다시 만들었습니다. 하치와레의 추가 팔을 제거했고, 포즈가 바뀔 때 이전 그림이 겹치는 현상도 없앴습니다. 치이카와·우사기의 대사는 짧은 감탄사 중심이고, 하치와레는 친근한 한국어 문장으로 반응합니다. 가격·등락률과 캐릭터 대사를 분리하여 정보는 정확히 읽을 수 있습니다. 최근 공식 영상 및 말투 자료의 확인 범위는 [참고 기록](docs/character-references-0.5.0.md), 이미지 최종 프롬프트는 [제작 기록](assets/character/PROVENANCE-0.5.0.md)에 있습니다.

시세 미제공 종목만 분리하고 나머지 시세를 계속 받습니다. 동일 모드 재연결 시 계좌 선택 유지, 등록가 일괄 저장, 검색 목록 부분 복구·재시도 제한, WS 구독 재선언, 80~300px 실제 펫 크기도 수정했습니다. 등록가는 기존처럼 최초 시세 수신 시점의 가격을 유지합니다.

**친구와 알림 설정 → 앱 업데이트**에서 확인할 수 있습니다. 앱은 시작 후와 6시간마다 새 버전을 확인하며, 새 버전이 있으면 소리 없이 펫 말풍선·트레이 메뉴·설정 화면으로 안내합니다. Windows 설치판은 다운로드 후 사용자가 재시작 설치를 누를 때 업데이트합니다. Mac은 Apple 서명 인증서가 없어, 사용자가 선택한 방식대로 새 버전 알림과 해당 CPU용 ZIP 다운로드를 제공합니다. 압축을 풀어 기존 앱을 교체하세요. 0.4.x에는 업데이트 기능이 없으므로 0.5.0은 한 번 직접 설치해야 합니다.

GitHub Releases에서 새 버전을 받아오며 Toss API 키를 업데이트 서버에 보내지 않습니다. 기존 암호화 키와 설정 호환을 위해 내부 저장소 이름 `Chiikawa Stocks`와 앱 ID `im.chii.stocks`는 유지합니다. [업데이트·릴리스 절차](docs/updates.md)를 참고하세요.

## 0.4.1 우사기의 평소 얼굴

우사기의 새 16포즈 이미지는 둥근 눈·곡선 눈썹·작은 입을 대부분 유지합니다. 눈을 크게 뜨거나 찡그리기, 크게 웃는 표정 대신 작은 손발 움직임과 몸 자세로 반응합니다. 산책 속도와 빈도는 유지하며, 상승에는 낮고 짧은 두 번의 점프, 하락에는 잠깐 멈칫한 뒤 가벼운 발 움직임을 사용합니다.

공식 YouTube를 다시 관찰한 기록은 `docs/usagi-references-0.4.1.md`, 생성 이미지와 최종 프롬프트는 `assets/character/PROVENANCE-0.4.1.md`에 있습니다.

## 0.4.0 하치와레와 우사기

**친구와 알림 설정 → 함께할 친구**에서 치이카와·하치와레·우사기를 선택하면 바로 적용되고 재실행 후에도 유지됩니다. 캐릭터별 미리보기에서 산책과 상승·하락 반응을 볼 수 있습니다. 캐릭터만 바꿀 때 시세 연결, 계좌 조회, 관심종목과 정기 알림 타이머를 유지합니다.

- 치이카와: 작은 보폭으로 조심조심 걷고, 소소한 점프와 눈물로 반응합니다.
- 하치와레: 주변을 구경하며 경쾌하게 걷고, 상승하면 두 번 폴짝이며 손을 듭니다. 하락하면 잠깐 눈물을 보인 뒤 마음을 추스릅니다.
- 우사기: 더 빠르게 통통 걷고 때로 방향을 바꿉니다. 0.4.1에서는 평소 얼굴을 유지하면서 짧은 점프와 작은 발 움직임으로 반응합니다.

새 이미지 각 16개 포즈와 캐릭터별 걸음 주기·휴식·속도·표정·말풍선을 적용했습니다. 공식 소개와 영상을 참고했고 하락 반응은 앱용으로 해석했습니다. 참고 기록은 `docs/character-references-0.4.0.md`, 제작 프롬프트와 투명 이미지 정보는 `assets/character/PROVENANCE-0.4.0.md`에 있습니다. 동작 줄이기에서는 고정 표정으로 표시하며 산책·점프·흐르는 눈물을 멈춥니다.

## 0.3.0 내 계좌와 더 잦은 산책

**계좌·자산**에서 토스증권 계좌를 선택하면 보유 주식의 수량, 평균 매수가, 현재가, 평가금액, 당일·전체 손익을 확인할 수 있습니다. 계좌 번호는 끝 네 자리만 표시하고, 자산은 1분마다 또는 **새로고침**으로 조회합니다. 국내 원화와 미국 달러 금액을 따로 표시하며, 전체 손익률은 API가 제공한 원화 환산 기준입니다. 이 화면은 **주식 자산**을 다루며 예수금·채권·옵션은 포함하지 않습니다.

**보유 주식 자동 추가**는 기본으로 켜져 있습니다. 선택한 계좌의 보유 주식을 기존 관심종목에 중복 없이 추가하고, 기존 알림 간격(기본 5분)과 등락 기준을 그대로 사용합니다. 정기 말풍선은 보유 주식부터 안내하며, ±5% 단계 알림도 함께 적용됩니다. 평균 매수가 대비를 선택하면 직접 입력한 매수가를 우선 사용하고, 입력값이 없는 보유 주식은 선택한 계좌의 평균 매수가로 계산합니다. 자동 추가를 끄거나 보유하지 않게 되더라도 이미 추가한 관심종목을 임의로 삭제하지 않습니다. 관심종목 100개 한도에 도달하면 추가하지 못한 개수를 표시합니다.

캐릭터는 실행 후 약 2초부터 걷기 시작하고, 한 번 산책한 뒤 4~9초 쉬었다 다시 이동합니다. 목적지까지 이동 거리는 140~280px이며, 기존 표정과 부드러운 걸음은 유지합니다. 연속 등락 알림 중에도 걸을 시간을 확보합니다. 산책 끄기와 운영체제의 동작 줄이기 설정을 켠 경우에는 계속 움직임을 줄입니다.

데모 계좌와 자산은 가상 데이터입니다. 실제 계좌 응답은 메모리에서만 사용하고, 계좌번호·보유 수량·평가금액을 설정 파일에 저장하지 않습니다. 자동으로 추가된 실제 보유 종목의 이름과 종목코드는 일반 관심종목처럼 저장됩니다.

## 0.2.2 산책과 말풍선

가격 안내와 등락 알림이 계속 들어와 산책 대기 시간이 매번 초기화되던 문제를 수정했습니다. 일반 말풍선을 띄우는 동안에도 조심조심 걸으며, 연속 등락 알림 사이에도 짧은 걸음을 이어갑니다. 산책을 끄거나 운영체제의 모션 감소를 켠 경우는 계속 존중합니다. 화면 가장자리에서 움직이지 않는 목적지를 선택하던 경우도 보완했습니다.

**친구와 알림 설정 → 말풍선 크기**에서 80~160%를 선택하고 **캐릭터 설정 저장**을 누르세요. 글자와 말풍선이 함께 커지고, 설정은 재실행 후에도 유지됩니다. 커진 말풍선은 화면 안에 보이도록 위치를 조정합니다.

Windows와 Mac 공통 모니터 드래그의 종료·복구 경로를 보완했습니다. 드래그 상태가 남아 산책을 막는 경우를 처리하며, Windows의 음수 화면 좌표와 혼합 배율도 테스트합니다. Windows 실기기 실행 여부는 `QA.md`에 별도로 기록합니다.

## 실행

로컬 배포 파일은 `release/0.5.0/`에 있습니다. GitHub의 정식 릴리스 공개 여부와 운영체제별 실행 확인 상태는 [검증 기록](QA.md)을 참고하세요. 이전 버전 파일은 보존했습니다. 개발 환경은 Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
```

처음 실행하면 **데모 시세**로 시작합니다. 데모 가격은 실제 주가가 아닙니다. API 키 없이 캐릭터 이동·점프·오열과 관심종목 설정을 확인할 수 있습니다. 설정 창을 닫아도 펫은 계속 실행되고 메뉴바/시스템 트레이에서 설정·보이기·숨기기·모니터 이동·종료를 선택할 수 있습니다.

## 실제 시세 연결

1. 본인의 토스증권 WTS → 설정 → Open API에서 `client_id`, `client_secret`을 발급합니다.
2. 같은 화면에서 이 컴퓨터가 사용하는 **공인 IP**를 허용 IP에 등록합니다.
3. 앱의 API 연결 화면에 값을 입력하고 저장한 뒤 실제 시세 연결을 실행합니다.
4. 연결 상태와 마지막 수신 시각을 확인합니다. 키를 채팅이나 소스 코드에 입력하지 마세요.

키는 Electron `safeStorage`를 통해 macOS Keychain/Windows DPAPI 기반으로 암호화해 사용자 데이터 폴더에 저장합니다. 렌더러에 키를 읽어오는 API는 없으며, 앱 패키지에 키를 포함하지 않습니다. 네트워크 접속은 메인 프로세스에서만 수행합니다.

토스증권은 같은 클라이언트에 유효한 토큰을 하나만 유지합니다. 같은 키로 다른 컴퓨터나 프로그램에서 새 토큰을 발급하면 기존 연결의 REST 인증이 취소될 수 있습니다. 인증 취소는 자동 재발급 경쟁을 일으키지 않도록 연결 오류로 표시합니다. 각 사용자는 각자 키를 사용해야 합니다.

## 동작

- 국내·미국 기본 각 10종목. 종목명·티커·종목코드로 검색해 최대 100종목 등록.
- 5분마다 가격 안내. 간격 변경 가능. 실시간 체결로 ±5·10·15·20·25·30% 진입을 감지.
- 같은 단계를 벗어났다가 다시 진입하면 다시 반응. 한 번에 여러 단계를 넘으면 가장 큰 단계로 한 번 반응.
- 기본 전일 종가 대비. 매수가·직접 지정 가격·관찰 시작 가격을 선택할 수 있음. 입력하지 않은 기준값은 알림 계산에서 제외.
- 프로그램 시작·재연결 첫 시세는 비교 시작점으로 사용. 놓친 과거 체결을 임의로 알림으로 만들지 않음.
- 시간외 포함, 시간대 제한 없음. 새 체결이 없는 종목은 마지막 체결가와 수신 시각을 표시하고, 오래된 가격은 갱신 대기로 구분. 휴장과 거래정지의 원인을 별도로 판정하지는 않음. 장이 닫혔거나 기기가 잠든 동안 실시간 가격을 만들지 않음.
- 펫을 끌어 다른 모니터로 직접 옮기고, 더블클릭해 설정을 열 수 있음. 전체 화면의 투명 부분은 클릭 통과. 트레이의 ‘보낼 모니터’로도 이동 가능.

## 제작과 검증

```sh
npm test
npm run build
npm run test:desktop
npm run test:roaming
npm run test:portfolio
npm run test:characters
node scripts/smoke-brand-updates.mjs
npm run dist:mac
npm run dist:win
node scripts/check-packages.mjs
node scripts/smoke-characters.mjs --packaged
node scripts/smoke-brand-updates.mjs --packaged
```

Mac Apple Silicon에서 `node scripts/smoke-packaged.mjs`는 패키지 자체를 **별도의 임시 데모 프로필**로 실행하여 검사합니다. 실제 사용자의 API 키를 열거나 변경하지 않습니다. `--demo-preview` 실행 옵션은 항상 데모 모드로 시작하고 API 키 저장·삭제를 막습니다.

macOS Apple Silicon/Intel ZIP과 Windows x64 설치 프로그램/ZIP을 생성하도록 구성했습니다. `.github/workflows/build-desktop.yml`은 각 운영체제에서 테스트·패키징하는 수동/태그 빌드입니다. 운영체제별 실제 실행 확인 결과와 배포 파일은 `QA.md`를 참고하세요.

현재 Apple Developer ID 서명·공증과 Windows 인증서 서명은 미완료입니다. Mac은 새 버전 알림과 수동 ZIP 교체를 제공하며, 향후 Mac 자동 설치를 도입할 때 서명·공증을 구성해야 합니다. OS 보안 기능을 끄도록 안내하지 않습니다.
