# 캐릭터 확장 구조

0.4.0에서는 치이카와·하치와레·우사기를 설정에서 선택한다. 캐릭터 식별자는 `config.characterId`로 저장한다. 이전 설정에 이 값이 없으면 `chiikawa`를 채우며 기존 관심종목·가격 기준·크기를 보존한다. 앱 ID, 제품 이름, API 저장소 위치는 이전 버전과 같다.

## 역할 분리

- `lib/characters.js`: 이름·설명·대표색·출시 여부·행동 프로필·접근성 설명·말풍선 문구. 세 캐릭터는 각자 다른 프로필을 사용한다.
- `lib/config.js`: 선택 가능한 식별자를 메인 프로세스에서 검증한다.
- `src/character-skins.js`: 캐릭터별 독립 이미지와 실측 프레임 좌표, 발 기준점, 눈물 위치.
- `lib/character-motion.js`: 시간에 따른 표정·위치·기울기·눈물을 계산하는 순수 함수. 대시보드와 바탕화면이 같은 동작을 사용한다.
- `src/character.js`: 프레임 전환과 부드러운 이동을 그린다. `mountCharacter(container, {characterId, size, action})`와 `setCharacter(id)`를 제공한다.
- `src/pet.js`: 캐릭터의 대기 시간, 걸음 속도, 짧은 이동·쉼의 길이를 읽어 화면 위 행동을 정한다.
- 시세 감시와 알림 단계는 캐릭터에 관계없이 동일하다. 캐릭터 설정만 바꿔도 API 재연결이나 감시 초기화를 하지 않는다.

## 현재 동작 (0.4.1)

| 친구 | 산책 | 상승 | 하락 |
|---|---|---|---|
| 치이카와 | 작은 걸음으로 걷고 4~9초 쉰다 | 잠깐 놀란 뒤 작게 폴짝인다 | 눈물이 고인 뒤 조용히 훌쩍인다 |
| 하치와레 | 더 경쾌하게 걷고, 잠깐 고개를 기울인다. 쉼은 3~7초 | 두 번 작게 뛰고 반갑게 손을 든다 | 놀라 잠깐 눈물을 보인 뒤 표정을 추스른다 |
| 우사기 | 기본 얼굴을 유지하며 작은 보폭으로 빠르게 걷는다. 간혹 방향을 바꾸고 2~5초 쉰다 | 얼굴을 크게 바꾸지 않고 짧고 낮게 두 번 폴짝인 뒤 기본 자세로 돌아온다 | 잠깐 멈칫하고 몸을 살짝 기울인 뒤 한쪽 발을 가볍게 움직이고 돌아온다 |

상승·하락의 핵심 동작은 실제 단계 알림의 약 2.4초 안에 보이도록 구성했다. 조용한 치이카와, 사교적인 하치와레, 예측하기 어려운 우사기를 구분하는 앱용 해석이며, 영상 프레임을 그대로 복제한 애니메이션은 아니다. 가격·등락률·데모 여부는 캐릭터 감탄사와 별도로 명확하게 표시한다. 투자 권유 문구나 소리는 넣지 않는다.

직접 확인한 영상 시점과 관찰 범위는 [0.4.0 캐릭터 참고 기록](character-references-0.4.0.md)에 정리했다. 성격 방향은 [공식 캐릭터 소개](https://www.chiikawaofficial.com/characters/)의 다정하고 긍정적인 하치와레, 활기차고 겁 없는 우사기 설명을 참고했다. 특히 하락 반응은 성격을 바탕으로 새로 구성한 앱용 표현이다.

0.4.1 우사기는 사용자의 지적과 추가 영상 관찰을 반영해 기본 눈·입·눈썹의 인상을 유지하도록 이미지를 다시 구성했다. 평소에는 가끔 눈을 감거나 입을 작게 움직이고, 가격 반응은 짧은 몸·발·귀의 움직임으로 전달한다. 우사기의 놀란 큰 눈, 찡그린 얼굴, 크게 벌린 입, 눈물은 사용하지 않는다. 산책 빈도·이동 속도·방향 전환 설정은 0.4.0과 같으며 화면 위 활동성을 유지한다. 추가 참고 범위는 [0.4.1 우사기 참고 기록](usagi-references-0.4.1.md)에 정리했다.

일반 말풍선과 잦은 알림이 계속되어도 0.3.0의 산책 보호 시간을 유지한다. OS에서 동작 줄이기를 켜면 모든 친구가 이동·기울기·점프·눈물 낙하·프레임 반복 없이 해당 표정 한 장만 표시한다.

## 이미지 프레임 계약

각 독립 투명 PNG는 4열 × 4행, 16개의 포즈다. 프레임은 행 우선으로 센다.

- 0~3: 기본, 눈 감기, 미소, 말하기
- 4~7: 네 단계 걷기
- 8~11: 상승 알아차림, 점프 준비, 공중, 기쁨 정착
- 12~15: 하락 놀람, 걱정/당황, 슬픔/발 구르기, 진정

우사기의 `usagi-atlas-v2.png`는 같은 16개 위치를 사용하되 표정 변화 대신 자세를 구분한다. 0~3은 기본·눈 감기·기본 자세 변형·작은 입 움직임, 4~7은 걷기, 8~11은 알아차림·웅크림·작은 점프·착지, 12~15는 멈칫·작은 기울임·한쪽 발 움직임·기본 자세 복귀다. 이 의미 차이는 우사기 타임라인에만 적용한다.

내부 액션명 `cry`는 기존 IPC와의 호환을 위해 유지한 하락 반응 식별자다. 모든 캐릭터가 치이카와처럼 울어야 한다는 뜻은 아니다. 우사기는 떨어지는 눈물을 사용하지 않는다.

## 다음 캐릭터를 추가할 때

1. 참고 이미지와 실제 행동을 확인하고 해당 캐릭터의 표정·동작 이미지를 별도 경로에 제작한다. 치이카와에 색만 바꾸는 방식으로 대체하지 않는다.
2. 렌더러의 캐릭터별 자산 정의에 이미지·프레임·동작 구성을 등록한다. `idle`, `walk`, `happy`, `cry`, `talk`, `sleep` 동작을 연결한다.
3. 카탈로그의 행동 수치·문구·접근성 설명과 순수 타임라인을 해당 성격에 맞게 조정한다. 공통 액션명에 각 친구의 표현을 대응한다.
4. 투명도, 발 기준점, 프레임 간 얼굴 비율, 작은 크기, 밝고 어두운 바탕, 감소된 모션 설정을 확인한다.
5. 완성된 캐릭터만 `available: true`로 바꾼다. 이름과 새 식별자가 렌더러·트레이·설정에 반영되는지 확인한다.

사용자 임의 파일 실행이나 외부 스크립트 플러그인 기능은 없다. 새 캐릭터 자료는 앱 업데이트에 포함한다.
