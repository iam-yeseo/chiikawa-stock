# 먼작주 0.5.2

Mac 다운로드본의 불완전한 서명을 고쳤습니다. Apple Silicon·Intel 앱과 내부 실행 파일에 무료 자체 서명(ad-hoc)을 적용하고, 배포 ZIP을 다시 풀어 서명 무결성을 검사합니다.

Apple 개발자 계정이나 공증을 사용하지 않은 배포입니다. 첫 실행 시 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 실행을 허용해야 할 수 있습니다. [Mac 설치·실행 안내](https://github.com/iam-yeseo/chiikawa-stock/blob/main/docs/mac-install.txt)를 먼저 확인해 주세요. 같은 안내를 `Meonjakju-0.5.2-Mac-Guide.txt`로 첨부합니다.

- Apple M 시리즈: `Meonjakju-0.5.2-mac-arm64.zip`
- Intel Mac: `Meonjakju-0.5.2-mac-x64.zip`
- Windows: `Meonjakju-0.5.2-win-x64.exe` (설치판), `Meonjakju-0.5.2-win-x64.zip`

Mac은 기존 앱을 종료하고 ZIP을 풀어 응용 프로그램 폴더의 앱을 교체해 주세요. 기존 사용자 설정과 API 저장소는 유지됩니다. Windows의 사용자 선택형 업데이트와 기존 산책 모드·시세 기능을 유지합니다.

검증 범위와 실제 다운로드 후 실행 결과는 [0.5.2 검증 기록](https://github.com/iam-yeseo/chiikawa-stock/blob/main/docs/verification/0.5.2/README.md)에 기록합니다. Chrome 실제 다운로드 → macOS 보안 설정에서 허용 → 0.5.2 실행을 확인했고, 공개 파일 10개의 해시와 업데이트 피드를 대조했습니다. Intel용 앱은 Rosetta 실행, Windows는 네이티브 CI 패키지 실행을 검증했습니다. Intel 실기기와 다른 macOS 버전은 미확인입니다.
