# 먼작주 0.5.0

치이카와도 주식을 해요가 **먼작주**로 바뀌었습니다.

- 첨부 코드 리뷰의 시세 부분 실패, 계좌 선택 유지, 검색 목록 복구, 요청 간격, 설정 저장 및 산책 처리 수정
- 치이카와·하치와레·우사기 16포즈 이미지 재제작과 팔이 겹쳐 보이는 현상 수정
- 캐릭터별 산책·상승·하락 반응과 말투 반영, 대사와 시세 정보 분리
- 새 로고, TmoneyRoundWind 글꼴, 분홍 제목 표시줄과 버전 표시
- 알림기록 탭과 불필요한 장식 문구 제거, 하단 투자 판단 책임 안내 추가
- Windows 설치판 업데이트 확인·다운로드·재시작 설치, Mac 새 버전 알림·CPU별 다운로드 추가

## 설치

- **Apple Silicon Mac:** `Meonjakju-0.5.0-mac-arm64.zip`
- **Intel Mac:** `Meonjakju-0.5.0-mac-x64.zip`
- **Windows:** `Meonjakju-0.5.0-win-x64.exe` 설치판 권장. ZIP도 제공합니다.

0.4.x에는 업데이트 기능이 없으므로 0.5.0은 직접 설치해야 합니다. 기존 앱을 종료한 뒤 새 앱으로 교체하세요. 기존 API 키와 설정은 같은 저장 위치를 사용합니다.

Mac은 Developer ID 인증서가 없어 **업데이트 알림·다운로드 방식**입니다. 다운로드 후 앱을 직접 교체해야 합니다. Windows도 다운로드와 재시작 설치를 사용자가 선택합니다. 앱에 공용 API 키나 GitHub 토큰을 넣지 않았으며 각자의 토스증권 API 키를 사용합니다.

검증 범위와 실제 버전 간 업데이트 검증의 한계는 [QA.md](../QA.md)에 기록했습니다.
