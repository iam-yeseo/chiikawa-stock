먼작주 0.5.2 Mac 설치·실행 안내

다운로드: https://github.com/iam-yeseo/chiikawa-stock/releases/tag/v0.5.2

1. 내 Mac에 맞는 파일을 받아 주세요.
   - Apple M 시리즈: Meonjakju-0.5.2-mac-arm64.zip
   - Intel Mac: Meonjakju-0.5.2-mac-x64.zip
   - 확인: Apple 메뉴 → 이 Mac에 관하여 → 칩 또는 프로세서

2. 실행 중인 먼작주가 있다면 메뉴 막대의 먼작주 메뉴에서 종료해 주세요.
   ZIP을 풀고 Meonjakju.app을 응용 프로그램 폴더로 옮겨 주세요.
   기존 앱이 있으면 교체합니다. 기존 설정 폴더는 지우지 마세요.

3. 응용 프로그램 폴더의 Meonjakju.app을 실행해 주세요.
   Apple의 확인을 받지 않은 앱이라는 안내가 나오면 창을 닫고,
   시스템 설정 → 개인정보 보호 및 보안 → 보안으로 이동해 주세요.
   Meonjakju의 '그래도 열기'를 누르고, Mac 로그인 인증 후 '열기'를 선택합니다.
   macOS 버전에 따라 버튼 이름이나 위치가 조금 다를 수 있습니다.

4. 설정 화면에서 버전 0.5.2를 확인해 주세요.
   API 없이 캐릭터만 사용하려면 친구와 알림 설정 → 산책 모드를 켜면 됩니다.

이 버전은 무료 자체 서명 방식으로 배포하며 Apple 공증을 받지 않았습니다.
첫 실행 또는 새 버전 설치 때 위의 허용 과정이 다시 필요할 수 있습니다.
신뢰하는 위 공식 배포 주소에서 받은 파일에만 실행을 허용해 주세요.

'손상되었기 때문에 열 수 없습니다'가 계속 나오거나 '그래도 열기'가 보이지 않으면
Mac 버전, 받은 ZIP 이름, 경고 화면을 보내 주세요.
회사·학교에서 관리하는 Mac은 관리자의 앱 실행 정책이 적용될 수 있습니다.

Apple 실행 안내: https://support.apple.com/ko-kr/102445
