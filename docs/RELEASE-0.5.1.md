# 먼작주 0.5.1

주식을 하지 않아도 친구와 함께할 수 있는 **산책 모드**를 추가했습니다.

- **친구와 알림 설정 → 산책 모드**를 켜면 바로 시작합니다. API 키가 필요하지 않습니다.
- 치이카와·하치와레·우사기가 각자 말투로 랜덤 대사를 보여줍니다. 위에는 캐릭터 이름, 아래에는 대사만 표시합니다.
- 캐릭터별 대사 12개를 준비했고, 같은 대사가 연속으로 나오지 않습니다. 약 18~32초마다 짧게 이야기합니다.
- 산책 모드에서는 주식 시세·등락 알림과 계좌 조회를 쉽니다. 기존 설정을 유지하고, 모드를 끄면 이전 주식 모드로 돌아갑니다.
- 선택은 즉시 저장되고 다시 실행해도 유지됩니다. 운영체제의 동작 줄이기 설정도 적용합니다.

0.5.0에서 앱 업데이트로 새 버전을 확인할 수 있습니다. Windows 설치판은 다운로드 후 재시작 설치를 선택하세요. Mac은 CPU에 맞는 ZIP을 내려받아 기존 앱을 교체하세요. 기존 API 키와 관심종목 설정은 유지됩니다.
