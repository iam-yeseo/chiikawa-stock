# 0.2.0 화면 디자인 참고

참고: [치이카와 마켓 공식 홈페이지](https://chiikawamarket.jp/), 2026-10-20 실제 브라우저 화면 확인.

## 참고한 시각 요소

- 코럴 공지 띠와 밝은 분홍 세로 줄무늬 헤더.
- 연노랑 가로 메뉴, 크림색의 작은 패턴 배경.
- 가운데에 놓인 둥글고 두꺼운 제목, 짙은 갈색 글자, 둥근 테두리.
- 캐릭터별로 탐색하는 구성과 부드러운 카드 구획.

앱에서는 상품 대신 관심종목·알림 기록·친구와 알림 설정으로 구성했다. 분홍색 카드에는 현재 친구와 모션 미리보기, 별도 친구 선택 영역에는 치이카와와 준비 중인 하치와레·우사기를 표시한다. 작은 창에서는 상단 높이를 줄여 시세와 모션 버튼을 먼저 볼 수 있게 한다.

사이트의 로고·상품 사진·배너를 앱 자산으로 복사하지 않았다. 앱 캐릭터는 사용자가 제공한 이미지로 새로 제작한 모션 파일을 사용한다. 글꼴과 UI는 외부 접속 없이 표시되며 시세 수신은 기존 메인 프로세스가 담당한다.

## 애니메이션

화면 전환, 대화상자, 버튼 반응, 미리보기 말풍선과 가격 갱신에 짧은 전환을 적용한다. 계속 움직이는 장식은 작게 제한하고, `prefers-reduced-motion`에서는 전환·장식·캐릭터 이동을 줄인다. 캐릭터의 원래 얼굴과 몸 비율은 스케일·회전으로 과장하지 않는다.

영상에 근거한 몸짓 관찰과 앱에서 정한 시간·거리의 구분은 `motion-references.md`에 기록했다.
