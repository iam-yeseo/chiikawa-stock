# 0.5.0 캐릭터·말투·로고 참고 기록

확인일: 2026-10-20. 이번 작업은 1화를 참고하지 않았다. 최근 공개된 한국어 공식 회차를 우선 확인했고, 일본 공식 채널의 최근 재공개 영상으로 전신 자세를 보충했다.

## 실제 확인 범위

- Chrome의 공식 YouTube 플레이어에서 재생 가능한 상태를 확인하고, 재생 위치를 이동하며 아래 시간의 실제 화면을 보았다. 썸네일만 보고 동작을 추측하지 않았다.
- 이 기록의 시각 관찰은 장면과 정지 프레임 비교다. 정확한 원작 프레임 속도나 이동 거리를 측정한 자료는 아니다.
- 한국어 공식 영상의 자막은 플레이어에서 `자막 사용 불가`로 표시됐다. 오디오를 도구로 직접 청취·전사하지 못했으므로 성우의 억양을 직접 분석했다고 주장하지 않는다. 한국어 문장 리듬은 공개 커뮤니티의 말투 재현과 공식 영상 댓글의 대사 언급을 보조 근거로 삼는다.
- 아래 앱 문구와 모션 수치는 작품 대사를 복제한 것이 아니라 이러한 관찰을 바탕으로 만든 앱용 창작안이다.

## 하치와레 한국어 말투

### 공개 커뮤니티 근거

- [더쿠: 너네 하치와레 말투 밈은 아니](https://theqoo.net/leagueoflegends/4370037814), 2026-10-09. 본문을 직접 확인했다. 짧은 도입 **“있잖아,”**, 되묻기 **“그거 보는거야?”**, 그리고 대상을 뒤늦게 이름 붙이는 형태가 나타난다.
- [인벤: 대충 하치와레 말투](https://www.inven.co.kr/board/maple/5974/7295049), 검색 결과상 2026-10-10. 검색 색인에는 “그거 말이야”로 시작하여 대상을 나중에 보충하는 문장이 보였다. 직접 열기는 404였으므로 **검색 색인에서만 확인한 보조 자료**다.
- 이들은 팬의 과장된 재현이다. 거친 표현, 실존인물 지칭, 게임 맥락은 앱에 옮기지 않는다. 공식 더빙의 정확한 대본이라고 인용하지 않는다.

### 앱에 적용할 문장 원칙

1. 치이카와는 `와…!`, `에…`, `흐으…` 등 짧은 소리와 표정으로 반응한다.
2. 우사기는 `야하!`, `우라!`, `우냐…` 등 짧은 외침만 사용한다. 경제 상황을 완성된 문장으로 해설하지 않는다.
3. 하치와레는 반말 기반의 밝고 부드러운 발견·질문형 문장을 쓴다. 가끔 `있잖아`로 시작하거나 `그 주식 말이야`처럼 대상을 뒤에 보충한다. 모든 문장에 동일한 유행어를 반복하지 않는다.
4. 가격·등락률·기준 가격·시간은 별도 정보 영역에 명확하게 표시한다. 최소 발화 캐릭터에게 설명문을 억지로 말하게 하지 않는다.
5. 하치와레의 낙관적인 성격을 주가 회복 예측, 매수·매도 권유 또는 수익 보장으로 바꾸지 않는다.

## 이미지와 모션 제작 기준

- 세 캐릭터 모두 **팔 두 개, 발 두 개**를 매 프레임 개별 확인한다. 손을 가슴·볼 앞으로 올린 프레임에서 기존 옆팔 돌출을 남기지 않는다.
- 손가락, 팔꿈치, 길게 분리된 팔다리, 추가 손·추가 발을 만들지 않는다. 꼬리는 몸 뒤에 한 개만 두며 손처럼 튀어나오지 않게 한다.
- 얼굴과 몸통이 이어지는 큰 윤곽을 유지하고 작은 팔·발만 바꾼다. 발 기준선과 몸통 크기가 프레임마다 흔들리지 않도록 한다.
- 서로 다른 팔 자세를 동시에 크로스페이드하면 정상 원본이어도 팔이 네 개처럼 보일 수 있다. 자세는 한 프레임만 표시하고, 이동·회전·스케일만 부드럽게 보간한다.
- 치이카와: 작은 보폭, 잠깐 멈칫하기, 낮은 기쁨 점프, 어깨를 모으는 울음.
- 하치와레: 열린 눈과 반듯한 자세, 작은 두 손 반응, 짧은 두 번의 기쁨 뜀, 하락 때 잠깐 움츠린 후 자세 회복.
- 우사기: 둥근 눈·작은 입·긴 귀의 정체성 고정. 빠른 발 교대나 짧은 방향 전환으로 개성을 주고, 하락 때 잠깐 멈추거나 몸만 기울인다. 치이카와처럼 얼굴을 크게 찌그러뜨리거나 계속 울리지 않는다.
- 위 동작은 원작 장면의 추출·복제가 아니라 앱 상황에 맞춘 새로운 표현이다. 16개 프레임 모두 밝고 어두운 배경, 실제 펫 크기에서 확인해야 한다.
