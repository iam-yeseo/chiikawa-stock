# 0.4.0 하치와레·우사기 참고 기록

확인일: 2026-10-20. 공식 소개의 설명, 브라우저에서 직접 본 장면, 이 앱의 연출 해석을 구분한다. 공식 영상은 Chrome의 YouTube 플레이어에서 음소거하고 일시 정지·시간 탐색으로 확인했다. 영상을 내려받거나 영상 프레임을 배포용 자산으로 추출하지 않았다. 아래 시간은 플레이어에 표시된 대략적인 초 단위 위치이며 보행 주기나 물리량의 실측값이 아니다.

## 공식 소개와 형태

- [일본 애니메이션 공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html): 하치와레·우사기 버튼을 각각 눌러 이름, 소개, 전신 그림을 확인했다. 하치와레는 밝고 긍정적인 치이카와의 친구로 소개된다. 우사기는 “우라”, “야하” 같은 소리를 크게 내는 친구로 소개된다.
- [영문 공식 캐릭터 소개](https://www.chiikawaofficial.com/characters/): 하치와레는 다정하고 긍정적이며 친구를 안심시키는 성격, 우사기는 활기차고 겁이 없으며 재미를 찾는 성격으로 설명된다. 이는 영상의 동작 속도를 측정한 근거와는 다르다.
- 하치와레 전신 그림: 흰색의 둥근 몸, 뾰족한 귀와 파란 갈라진 머리 무늬, 작은 팔·발, 분홍 볼. 머리 무늬의 꼭짓점과 두 귀를 유지해야 한다.
- 우사기 전신 그림: 연한 크림색 몸, 분홍 안쪽이 있는 긴 귀, 둥근 머리·몸통, 곡선 눈썹, 짧은 팔·발. 귀까지 포함한 전체 높이를 다른 캐릭터와 동일하게 잘라내지 않는다.
- 공식 페이지의 본체 이미지 출처: [캐릭터 모음 이미지](https://www.anime-chiikawa.jp/images/characters/img_charapage.png). 렌더링된 페이지의 CSS 배경 주소로 확인했다. [하치와레 선택 버튼](https://www.anime-chiikawa.jp/images/characters/bt_chara_02.png)과 [우사기 선택 버튼 활성 상태](https://www.anime-chiikawa.jp/images/characters/bt_chara_03_on.png)도 확인했다.

## 앱에 적용하는 연출 해석

- **하치와레 산책:** 밝고 안정적인 짧은 발걸음, 작은 상하 움직임과 팔 흔들기. 몸통을 계속 과장해서 늘이거나 회전시키지 않는다.
- **하치와레 상승:** 미소를 먼저 읽을 수 있게 하고 팔을 벌려 기뻐하며 짧게 뛴다. **하락:** 놀라거나 걱정하는 표정, 눈가·손의 작은 변화, 잠깐의 위축 후 다시 자세를 잡는다. 긍정적인 성격은 하락 사실을 숨기거나 상승처럼 표현한다는 뜻이 아니다.
- **우사기 산책:** 세 친구 중 더 빠른 짧은 이동과 뜀, 잠깐 멈추는 자세를 조합한다. **상승:** 귀와 짧은 팔이 읽히는 더 큰 뜀. **하락:** 놀란 움찔·발 구르기·풀이 죽는 자세로 상승과 구분한다. 하락 표정의 순서와 지속 시간은 이 앱을 위해 만든 해석이다.
- 산책 간격, 이동 거리, 주가 반응 시간, 점프 높이와 횟수는 화면 위에 상시 표시되는 프로그램에 맞춘 앱 설정값이다. 본 영상에서 그대로 추출한 수치가 아니다.
- 산책 빈도를 늘려 달라는 사용자 요청을 유지한다. 차분한 표정 표현과 긴 정지 시간은 같은 개념이 아니다. 반복 말풍선과 연속 알림이 산책을 영구히 막지 않아야 한다.
- 공식 설명과 일부 장면을 참고한 앱용 새 그림·모션이다. 원본 애니메이션 전체의 완전한 재현이나 공식 배포 자산이라는 표현을 사용하지 않는다.
